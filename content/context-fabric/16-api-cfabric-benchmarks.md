# API Reference: cfabric_benchmarks

> Source: [https://context-fabric.ai/docs/api/cfabric_benchmarks](https://context-fabric.ai/docs/api/cfabric_benchmarks)

Context-Fabric Benchmarking Suite.

A comprehensive benchmarking package for comparing Context-Fabric and Text-Fabric performance across memory usage, query latency, and scaling characteristics.

## Submodules

| Module | Description |
|--------|-------------|
| [analysis](https://context-fabric.ai/docs/api/cfabric_benchmarks/analysis) | Statistical analysis module for benchmark results |
| [cli](https://context-fabric.ai/docs/api/cfabric_benchmarks/cli) | Command-line interface for cfabric benchmarks |
| [corpora](https://context-fabric.ai/docs/api/cfabric_benchmarks/corpora) | Corpora management utilities for downloading and validating test corpora |
| [generators](https://context-fabric.ai/docs/api/cfabric_benchmarks/generators) | Query validation for latency benchmarks |
| [models](https://context-fabric.ai/docs/api/cfabric_benchmarks/models) | Pydantic models for benchmark configuration and results |
| [output](https://context-fabric.ai/docs/api/cfabric_benchmarks/output) | Output utilities for benchmark results |
| [queries](https://context-fabric.ai/docs/api/cfabric_benchmarks/queries) | Hand-curated search queries for benchmarking |
| [runners](https://context-fabric.ai/docs/api/cfabric_benchmarks/runners) | Benchmark runners for memory, latency, and progressive loading tests |
| [visualization](https://context-fabric.ai/docs/api/cfabric_benchmarks/visualization) | Visualization tools for benchmark results |
